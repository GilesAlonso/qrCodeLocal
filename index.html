About

This QR code generator is built with vanilla HTML, CSS, and JavaScript - no external libraries or dependencies. It implements the QR code specification including Reed-Solomon error correction, data encoding, and optimal mask pattern selection.

Features:

  • Support for text, URLs, and numeric data
  • Four error correction levels (L, M, Q, H)
  • Automatic QR version selection (1-10)
  • Optimal mask pattern selection
  • PNG download and clipboard copy
  • Responsive design for mobile and desktop

100% Client-Side • No Data Uploaded • Pure Vanilla JS
